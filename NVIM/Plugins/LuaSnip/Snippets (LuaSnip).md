# Description

## What's Included:

1. **LuaSnip v2** - The latest version with JavaScript regex support
2. **friendly-snippets** - [Friendly Snippets](https://github.com/rafamadriz/friendly-snippets) is a collection of useful snippets for various languages
3. **Integration with nvim-cmp** - Your completion menu will now show snippets
4. **Automatic snippet loading** - Snippets are loaded automatically

## Key Features:

- **Snippet Expansion:** Press `<Tab>` to expand snippets or jump to next node
- **Navigation:** Use `<C-k>` and `<C-j>` to jump between snippet nodes
- **Choice Selection:** Use `<C-l>` and `<C-h>` to cycle through choices
- **Visual Indicators:** Active snippet nodes are highlighted with colored dots
- **History:** Snippet history is maintained for easy re-use


## How to Use:
1. Restart Neovim - The plugins will be automatically installed
2. Type a snippet trigger (e.g., for in JavaScript, def in Python)
3. Press `<Tab>` to expand the snippet
4. Navigate through the snippet using the keymaps above




# Key Bindings


- `tab` takes you to the next section in the snippet

- `shift + tab` takes you to the previous section
