# Your tools, one useful step at a time

This vault is your tutorial and reference library for the tools you use on Little brother. It already contains notes on Neovim, LazyGit, and the `nav` utility. Start with a task you want to perform; you do not need to learn the entire editor first.

## I forgot how our links work

Open [[NVIM/Code Links - Follow a link and copy an excerpt|Follow a link and copy an excerpt]]. It walks through the custom linking feature with a small Python file you can practice on.

For links written in Obsidian, see [[Obsidian/Code Links - A practical introduction|Code Links in Obsidian]]. This includes directory links, excerpts, and reference groups.

## I want to get comfortable in Neovim

Start with [[NVIM/Neovim - Your first editing session|Your first editing session]]. Then use the existing [[NVIM/File Navigation|File Navigation]] note when you want more movement and indentation commands. Neovide is the graphical window; Neovim is the editor inside it, using your existing configuration.

## I want to practice the keys

Open [[NVIM/First keys - practice|First keys — practice]] in Reading View. Study Studio supplies twelve questions in three small groups. After recalling a command, try it in the editable `NVIM/practice.txt` file. Uppercase and lowercase keys are graded separately.

## I want to open something from Finder

See [[Utilities/Finder - Code files and iTerm folders|Code files and iTerm folders]]. Code files open in Neovide. The iTerm folder action has a Finder shortcut.

## I have an idea for a customization

Put it in [[NVIM/Customization ideas|Customization ideas]] while it is fresh. Describe the task you want to make easier. We can check whether the feature already exists before adding another plugin or shortcut.

The gallery and slide tutorials can grow here as you use them. Existing notes remain in their original folders.
